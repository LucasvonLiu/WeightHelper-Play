# 核心交互架构与 AI 容错设计

## 1. 架构设计原点：做减法与极速流转

作为一款“轻量化”饮食记录工具，我们的核心交互架构不应围绕“如何展示更多数据”来设计，而应围绕**“如何让数据流转得更快”**来构建。传统的“首页 -> 搜索 -> 列表 -> 选择克重 -> 确认”的深层级漏斗必须被彻底抛弃。

### 1.1 极简信息架构 (Information Architecture)
App 的底部导航（Tab Bar）严格限制为 3 个：
1. **[相机/记录] (核心态，默认首页)**：占据视觉 C 位。打开 App 直接进入取景框或语音输入界面。
2. **[日历/足迹]**：以时间轴形式展示历史记录与每日的热量缺口/达标情况。
3. **[我的/设置]**：极简的数据看板、目标设定（如减重/维持）、以及偏好设置（如屏蔽特定过敏原）。

## 2. 核心输入交互设计：零摩擦捕获

我们要让用户感觉到，记录饮食就像给朋友发一条微信一样简单。

### 2.1 视觉输入 (Computer Vision)：先捕获，后修正
*   **交互逻辑**：
    *   用户在【相机】Tab 按下快门拍摄餐盘。
    *   **异步处理掩护**：系统瞬间显示“已保存，您可以开始享用美食啦！”，并自动将照片推入后台队列进行 API 调用（如百度/阿里云视觉接口）。
    *   **拒绝加载动画**：绝对不能让用户盯着转圈的加载动画等待 3.5 秒。这 3.5 秒的 API 延迟必须在用户锁屏吃饭的物理时间里被消化掉。
*   **结果触达**：处理完成后，通过本地静默通知或在下次打开时在日历中自动生成记录草稿。

### 2.2 语音与自然语言输入 (NLP)：一句话记录
*   **场景**：双手被占用，或者食物已经吃完无法拍照（如路边摊吃了个包子）。
*   **交互逻辑**：
    *   在相机页提供明显的【语音麦克风】按钮。
    *   用户说出：“早上吃了一屉小笼包和一杯半糖豆浆”。
    *   大模型（LLM）在后台将其解析为结构化的 JSON 数据（食物：小笼包，份量：一屉；食物：豆浆，修饰词：半糖，份量：一杯），并自动映射底层食物库卡路里。

## 3. AI 的“不确定性”管理与容错机制 (人在回路)

AI 永远无法 100% 猜透一碗汤里放了多少克猪油（隐形卡路里问题）。如果假装 AI 是绝对权威的，一旦误差暴露，信任就会崩塌。因此，我们必须设计优雅的**“人在回路 (Human-in-the-loop)”**机制。

### 3.1 置信度分层与降级策略
系统后台需要根据 AI 视觉 API 返回的置信度（Confidence Score）来决定交互界面的形态：
*   **高置信度 (>85%)**：例如识别出清晰的苹果、水煮蛋。直接记录，无需弹窗打扰用户，仅在卡片上标注一个微小的 `[AI 确信]` 绿标。
*   **中等置信度 (60% - 85%)**：例如识别出一盘中式炒菜。
    *   **交互动作**：记录为草稿状态，界面底部弹出一个极轻量的浮层提示：“检测到红烧肉，外卖可能偏油。”
    *   **微调滑块**：提供一个丝滑的阻尼滑块：`[偏少吃一点] —— [标准份量] —— [今天吃撑了]`，用户拖动即可瞬间成倍调整热量，避免去输入具体的克数。
*   **低置信度 (<60%) 或无法识别**：
    *   **拒绝重新搜索**：绝对不能弹出一个空白搜索框让用户从头开始。
    *   **交互动作**：给出 3 个最有可能的选项供一键点击（基于图片相似度或该用户该时段的历史高频饮食）；或者引导用户长按语音补充一句“这是宫保鸡丁”。

### 3.2 智能默认值与记忆功能
*   当系统识别出“米饭”时，它不会问用户“几克？”，而是直接根据用户的性别和基础代谢率，填入一个**智能默认值**（如：标准小碗 150g）。
*   **习惯记忆**：如果用户连续三天把“标准小碗”上调为“大碗”，系统从第四天起识别到米饭就会默认填入“大碗”的热量。越用越懂你。

## 4. 情感化体验：把冷冰冰的数字变成有温度的陪伴

传统的红绿灯警告（超过热量显示刺眼的红色）会带来极强的剥夺感和挫败感。我们要用积极心理学重塑这一体验。

### 4.1 大模型驱动的情绪伴侣
*   每一次打卡不仅是数据的录入，更是和 AI 伴侣的一次简短对话。
*   **正向激励**：即使用户输入了一杯高热量的全糖奶茶，AI 也不会说“你超标了，这很糟糕”，而是说：“哇，全糖奶茶一定很解压！偶尔补充快乐水没问题，我们晚上少吃几口碳水就能完美平衡啦~ 🥤”

### 4.2 非惩罚性游戏化（成长反馈）
*   引入类似“遇见你的种子”的机制。
*   **核心逻辑**：只要用户**诚实地记录了饮食（无论超标与否）**，那颗代表健康的虚拟种子就会获得水分和阳光并成长。
*   **价值**：将奖励与“自律度”解绑，与“诚实记录的连续性”绑定。这能极大降低用户的“饮食羞耻感”，保证次日和七日的超高留存率。
