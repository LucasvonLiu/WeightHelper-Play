# 📸 WeightHelper

**欢迎来到 WeightHelper！** 一款基于前沿大语言模型（LLM）的智能饮食追踪应用。只需拍下食物照片，AI 即可帮您秒算卡路里与三大营养素，轻松管理日常饮食！🥗✨

## ✨ 核心功能

- **🤖 AI 视觉识别与智能拆解**：拍照上传食物，利用 Google Gemini 视觉模型秒速估算热量、碳水化合物、蛋白质和脂肪。AI 能够智能识别复杂的混合餐食，自动按“份”拆解食物结构。
- **🍽️ 灵活精准的份数调整**：不论是只吃了 1/4 份、半份，还是连吃 3 份，你都可以通过营养卡片轻松调整摄入比例，系统会自动重算热量，比传统死板的“克重输入”更符合人类直觉。
- **🌍 跨时区家庭共享**：内置基于 `moment-timezone` 的时区管理与世界时钟（UTC 偏移）时间戳显示，无论家人分布在北京、柏林、纽约还是休斯敦，都能在同一个云端系统中无缝追踪并分享健康记录。
- **📊 动态营养追踪仪表盘**：首页提供直观的环形图，实时展示每日卡路里余量及宏量营养素（蛋白质、碳水、脂肪）的精确占比，健康进度一目了然。
- **🎛️ 智能双引擎与高可用架构**：
  - **模型灾备机制（Fallback）**：后端内置多模型自动降级策略，智能应对免费 API 额度耗尽或 429 限流报错，保障服务全天候在线。
  - **无缝数据库切换**：开发环境自动使用 SQLite 零配置极速启动；生产环境自动识别环境变量，无缝对接 PostgreSQL 云端数据库。
- **💅 现代流畅的交互体验**：磨砂玻璃质感的分析动效、所见即所得的极简 UI 布局，专为移动端操作习惯深度打磨。

## 🚀 如何运行与安装

### 环境要求
- Node.js (建议 v18+)
- npm 或 yarn

### 快速启动

1. **克隆项目到本地**：
```bash
git clone https://github.com/LucasvonLiu/WeightHelper.git
cd WeightHelper
```

2. **安装依赖**：
```bash
npm install
```

3. **配置环境变量**：
复制 `.env.example` 为 `.env` 并填入你自己的 AI API 密钥和相关配置：
```bash
cp .env.example .env
```
*(必填：需要配置 `GEMINI_API_KEY`，可前往 Google AI Studio 获取免费密钥)*

4. **启动服务**：
```bash
npm run dev
```

启动后，打开浏览器访问 `http://localhost:3000` 即可开始体验。
