# 📸 WeightHelper

**欢迎来到 WeightHelper！** 一款基于前沿大语言模型（LLM）的智能饮食追踪应用。只需拍下食物照片，AI 即可帮您秒算卡路里与三大营养素，轻松管理日常饮食！🥗✨

## ✨ 核心功能

### 🍎 极简记录体验
- **拍照即算**：上传照片，AI 自动拆解复杂餐食并估算热量及三大营养素。
- **滑动调份数**：支持 1/4 份、半份等灵活选择，热量自动重算，告别繁琐的“克重输入”。
- **可视化追踪**：环形仪表盘实时展示卡路里余量与碳水/蛋白/脂肪配比。

### 🌍 专为家庭设计
- **跨时区同步**：内置绝对时间与 UTC 偏移转换。家人无论在北京还是纽约，共用一套系统时间轴不乱。
- **多账号隔离**：安全的登录机制，全家人记录各自的饮食，互不干扰。

### ⚙️ 极客级高可用架构
- **AI 灾备引擎**：自动识别限流报错（429），无缝降级切换备用大模型，服务永不掉线。
- **双数据库自适应**：开发环境自动挂载 SQLite 极速启动；云端生产环境自动直连 PostgreSQL。

## 🚀 如何运行与安装

### 环境要求
- Node.js (建议 v18+)
- npm 或 yarn

### 快速启动

1. **克隆项目到本地**：
```bash
git clone https://github.com/LucasvonLiu/WeightHelper.git
cd WeightHelper
```

2. **安装依赖**：
```bash
npm install
```

3. **配置环境变量**：
复制 `.env.example` 为 `.env` 并填入你自己的 AI API 密钥和相关配置：
```bash
cp .env.example .env
```
*(必填：需要配置 `GEMINI_API_KEY`，可前往 Google AI Studio 获取免费密钥)*

4. **启动服务**：
```bash
npm run dev
```

启动后，打开浏览器访问 `http://localhost:3000` 即可开始体验。
