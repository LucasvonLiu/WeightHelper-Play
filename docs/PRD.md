# WeightHelper 产品需求文档 (PRD)

## 1. 产品概述
WeightHelper 是一款面向**减脂/健身人群**的极简 AI 饮食记录工具。旨在解决传统卡路里记录应用“手动输入繁琐、估算难”的反人类痛点。通过多模态 AI 大模型，用户只需拍照，即可自动识别食物、估算分量并计算卡路里及宏量营养素。

## 3. 产品定位与目标用户
*   **目标用户**：减脂、增肌、健身人群，以及需要精确控制日常热量摄入的健康自律人群。
*   **核心痛点**：不知道食物热量；懒得打字搜索；不知道自己吃的食物到底多少克。
*   **产品价值**：“拍照即记录”，极大降低记录门槛，提供直观的营养反馈。

## 4. 核心功能模块 (Core Features)

### 4.1 核心动作：拍照即识别 (AI Vision)
*   **操作流**：点击“拍照/上传” -> AI 呈现扫描动画 -> 识别出食物种类（如：西兰花、煎鸡胸肉）。
*   **关键能力**：AI 需具备一定的“分量”估算能力（例如基于餐具大小或其他参照物估算克数）。

### 4.2 数据解析与结构化 (Nutritional Analysis)
*   **营养计算**：根据识别出的食物和分量，自动换算出总热量（大卡）以及三大营养素（碳水、蛋白质、脂肪）。
*   **结果展示**：通过直观的环形图展示（如 UI 草图所示）。

### 4.3 日记与追踪 (Tracking & Dashboard)
*   **日记报表**：记录早/中/晚/加餐，生成每日摄入报表。
*   **目标对比**：实时显示今日剩余热量额度，帮助用户控制饮食。

### 4.4 互动与建议 (AI Coaching - 进阶)
*   **饮食评价**：AI 根据摄入情况给出个性化短评（例如：“这顿脂肪略高，晚餐建议选择高纤低脂的蔬菜沙拉”）。

## 5. 技术选型建议 (Tech Stack)

### 5.1 前端呈现 (Frontend)
*   **形态**：Web App (React/Vite) 或 微信小程序 (Taro)。
*   **UI 库**：原生 CSS / Tailwind CSS，强调现代化的毛玻璃与渐变设计。
*   **优势**：门槛最低，用户无需下载 App，随用随开。

### 5.2 后端服务 (Backend)
*   **框架**：Node.js (NestJS) 或 Python (FastAPI，便于对接各种 AI 模型)。
*   **数据库**：PostgreSQL (存储用户日记与设置) + Redis (缓存)。

### 5.3 AI 大模型 (AI Models)
*   **视觉识别**：调用 Gemini 1.5 Pro / GPT-4o 的 Vision API。利用其自带的零样本识别与常识推理能力，无需自建图片分类模型。
*   **数据校验**：可结合 FatSecret API 进一步校准 AI 输出的热量准确度。

## 6. 实施路径 (Roadmap)

### 第一阶段：MVP（最小可行性产品）- 核心体验验证
*   **目标**：验证 AI 识别食物的准确度和用户体验“哇塞”感。
*   **功能**：单页 Web App。用户上传/拍摄一张照片，页面播放炫酷扫描动画，返回食物名称、克数、热量和三大营养素。
*   **不包含**：暂不开发账号登录、历史记录、数据库存储等复杂业务。

### 第二阶段：留存与追踪
*   **目标**：让用户持续使用。
*   **功能**：引入账号系统、每日目标设定、历史日历、简单的统计报表。

### 第三阶段：商业化与拓展
*   **目标**：提供增值服务。
*   **功能**：AI 饮食周报分析、定制化饮食计划、付费解锁 AI 营养师 1对1 咨询服务。
